Features

Everything Discord doesn't give you

A Discord-style window with superpowers. Everything stays on your PC: your token only ever goes to discord.com.

🧹

Bulk delete your messages

Tick DMs, channels, threads or whole servers. Filter by keywords, dates, pictures, links. Preview in red before anything is deleted.

⊘

See deleted messages

Someone deleted a message in your DMs? You can still read it, with what it said before it was edited.

👻

Ghost ping catcher

Someone @mentioned you in a server and deleted it right away? You'll know who, where and what they said.

💔

Friend list alerts

Get told when you're no longer friends with someone, even if it happened while your PC was off.

💬

Chat like in Discord

Send, reply, edit, upload files, paste screenshots and react. New messages and "typing…" appear live.

🎞️

GIFs & videos play

Tenor GIFs loop, videos play inline, emojis and reactions look like Discord's, including custom server emojis.

🔖

Saved messages

Bookmark any message. It stays on your PC, even if it gets deleted on Discord later.

📦

Every chat you ever used

Import your Discord data package to find closed DMs and old chats, then clean them too.

✎

See unedited messages

When someone edits a message, you still see what it said before, right under it.

🗂️

Automatic backups

Save a full copy of chosen chats every day or week, with pictures and files. The newest copies are kept.

🖼️

Media gallery

Every picture, video, file and link ever posted in a chat, in one place.

🌍

5 languages

English, Français, Español, Português and Deutsch. Picked automatically from Windows.

🍓

Always-on option

Run the tiny logger on a Raspberry Pi or Android phone to catch deleted messages 24/7, even when your PC is off.

🩺

Check my setup

One click tests everything (Discord, emojis, videos, logger) and gives you a report to copy if you need help.

🪶

Light in the background

Lives next to the clock when closed. The background logger uses about 20–30 MB of RAM and almost no CPU.

How it works

Up and running in two minutes

No install needed with the single .exe. Or use the setup wizard for a Start menu shortcut and a clean uninstall.

Download

Get the zip, unzip it, double-click DiscordMessageCleaner.exe.

Log in

Paste your token (the app shows you how to find it), or try the demo first.

Pick chats

Browse your DMs and servers like in Discord and tick what to clean.

Clean

Run a dry run to see what would go, then press Start. Pause or stop any time.

FAQ

Good questions

Is it free?

Yes, 100% free and open source (MIT license). No ads, no account, no payments.

Where does my token go?

Only to discord.com. Saved accounts are encrypted with Windows' own protection (DPAPI) and only work on your PC. The code is public on GitHub so anyone can check.

Can my account get banned?

Discord's Terms of Service don't allow automation on user accounts. Most people use tools like this without problems, but there's always a risk. Use it at your own risk and don't spam.

Can it see messages deleted while my PC was off?

Partly. When your PC turns back on, it finds messages it had already seen that were deleted or edited meanwhile. To catch everything 24/7, you can run the small logger on an always-on device (old laptop, Raspberry Pi, Android with Termux) and import its file.

Windows says "Windows protected your PC"

That's SmartScreen. It shows up for new apps that aren't signed with a paid certificate. Click More info → Run anyway. You can also build the .exe yourself from the source code.

Which languages?

English, French, Spanish, Portuguese and German. Change it in Settings ⚙ → Language.

Something doesn't work. What do I do?

In the app: Settings ⚙ → Check my setup. It tests everything and gives you a report you can copy into a GitHub issue.

Does it slow down my games?

No. The background part sleeps until Discord sends something: a tiny signal every ~41 seconds plus your messages.
