Changelog

7.4.0 LATEST

November 2026
  • Mute chats and servers or get only @mentions; unread and mention marks on server icons; Ctrl+Shift+M.
  • @mention suggestions while typing and a GIF picker.
  • Search filters: from:, mentions:, has:, before:, after:, during:, pinned:.
  • Members panel for server channels, 10-second undo for single deletes, last chat reopens, Alt+↑/↓.
  • Logger dashboard and edit-history export.

7.3.0

November 2026
  • Use it as your everyday Discord: the 🧹 button hides every cleaning tool, and the ⊘ Deleted messages icon can be hidden too.
  • Friends page with Online / All / Pending / Blocked, Add Friend, accept, remove and block, with status dots.
  • Set your status (Online, Idle, Do Not Disturb, Invisible) and a custom status.
  • Profile cards, pinned messages, edit your display name and About me.
  • Calls open in the Discord app.

7.2.0

November 2026
  • Role mentions show the role's real name (for example @Moderators) instead of "@role".
  • Right-click a message → Copy message link.
  • Unread messages are counted in the window title, like Discord.
  • Logger: Keep deleted messages for N days (0 = forever). Older entries and their saved pictures are removed automatically, also by the always-on logger.
  • A web version you can use in the browser (no download): see the README.

7.1.0

November 2026
  • See unedited messages: the original text of edited messages shows under them (DMs even when the app was closed)
  • Always-on logger: one-command setup for Raspberry Pi / Linux and Android (Termux), starts by itself after a reboot; the app auto-imports the synced file
  • Search and export all saved deleted messages (HTML, text, JSON)
  • Muted chats for the logger (noisy groups, bots)
  • Scheduled backups: save full copies of chosen chats every day or week, keeps the 4 newest
  • Media gallery: pictures, videos, files and links of a chat
  • Check my setup: one-click diagnostics with a copyable report
  • New languages: Español, Português, Deutsch

7.0.0

November 2026
  • Chat from the app: send, reply, edit, upload, paste screenshots, emoji picker, live updates and typing
  • Discord-style emojis and clickable reactions, custom and animated server emojis
  • GIFs loop and videos play inside the app
  • Rich text: bold, italic, spoilers, links, mentions, headers
  • Runs next to the clock when closed, with notifications
  • Ghost-ping catcher, friend-list alerts, saved messages, offline catch-up
  • Sharp icon at every size; GitHub website and automatic builds

6.2.0

November 2026
  • Deleted-messages logger for DMs, running in the background with very low usage

6.0 – 6.1

November 2026

  • Demo mode, first-time tour, French, themes, multiple accounts, auto-clean rules
